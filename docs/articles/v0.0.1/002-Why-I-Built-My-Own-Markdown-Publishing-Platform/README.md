# Article 002

## Title

Why I Built My Own Markdown Publishing Platform Instead of Using Existing Tools

---

## Objective

Explain the engineering decisions behind building a custom publishing platform instead of relying solely on existing tools.

This article is not about replacing Pandoc or other publishing tools.

It is about designing an engineering architecture that treats documentation and publishing as a repeatable, maintainable, and extensible software system.
