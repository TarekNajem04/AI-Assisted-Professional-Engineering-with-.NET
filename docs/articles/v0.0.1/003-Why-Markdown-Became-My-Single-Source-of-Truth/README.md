# Article 003

## Title

Why Markdown Became the Single Source of Truth

---

## Objective

Explain why Markdown was chosen as the project's Single Source of Truth (SSOT) and how this architectural decision influences every aspect of the publishing platform.

This article is not about Markdown syntax.

It explains the engineering philosophy behind separating knowledge from presentation and treating Markdown as the canonical representation of the manuscript.

---

## Key Topics

* Single Source of Truth
* Knowledge Architecture
* Separation of Content and Presentation
* Reproducible Publishing
* Documentation Engineering
* Maintainability
* Long-Term Scalability
