# Medium Description

AI-Assisted Professional Engineering with .NET is an open engineering project that documents the complete journey of writing a modern software engineering book in public.

The repository combines three major components:

- A bilingual technical manuscript.
- A production-grade Markdown publishing pipeline.
- A transparent engineering workflow documenting every stage of the project's evolution.

Rather than publishing only the finished book, the project exposes the entire engineering process, including repository organization, publication strategy, automation, tooling, release management, and long-term architectural decisions.

Readers can follow the project section by section while observing how a professional technical publication evolves from concept to completion.

# Long Description

AI-Assisted Professional Engineering with .NET is more than a technical book.

It is a complete engineering project built in public.

The repository demonstrates how modern AI-assisted software engineering can be combined with disciplined engineering practices to produce professional technical publications.

Alongside the manuscript itself, the repository includes a production-grade publishing toolchain capable of transforming Markdown sources into high-quality DOCX and PDF documents through an extensible export architecture.

The project emphasizes reproducibility, maintainability, transparency, automation, and long-term quality.

Every public release documents measurable progress, allowing readers to follow both the evolution of the book and the engineering decisions behind it.

# Publishing Toolchain Highlights

The repository contains a reusable publishing system designed for professional technical documentation.

Current capabilities include:

- Markdown preprocessing
- Multi-stage export pipeline
- Style profile architecture
- Custom Pandoc integration
- DOCX generation
- PDF generation
- Cover generation
- Syntax highlighting
- Mermaid rendering
- Project-specific publishing conventions

The publishing system is intentionally designed to remain modular and extensible, allowing future export engines and publication styles to be added with minimal effort.
